Скрипты
==

csv2pline_scr.sh
--

    Преобразует .csv файл с координатами точек в .scr файл, пригодный для
    прямого перетаскивания (drag-and-drop) в AutoCAD, с получением замкнутой
    полилинии.
    
    Использование: csv2pline_scr.sh [опции] <входной_файл> [выходной_файл]
    Опции:
      -t: добавлять текст с номерами точек
      -c: добавлять круги вокруг точек
      -n: входной файл не включает номера точек (т.е. нумерация по порядку)
      -x: X-координата идёт первой (по умолчанию: геодезический порядок Y X)
      -i <номер>: игнорировать точку; параметр можно указывать несколько раз,
        -1 = последняя точка
    
    Входной файл может содержать лишние табуляции и пробелы, переводы строк в
    ошибочных местах, запятые в качестве разделителя плавающей точки: это всё не
    имеет значения до тех пор, покуда значения идут тройками или парами
    (в последнем случае следует использовать параметр -n).

pvc.sh
--

    Калькулятор объёма пирамиды (усечённой и полной)

    Использование: pvc.sh <ширина1> <длина1> <высота> [<ширина2> <длина2>]
    
make_agreement.sh, make_act.sh, make_bill.sh
--

    Скрипты для составления типовых договоров, актов и счетов. Работают на
    основе LibreOffice (точнее используют его форматы и используют его для
    окончательной выгрузки в docx и xlsx).
    
    Для работы требуются заранее заготовленные шаблоны в формате .fodt и .fods
    (см. начало каждого скрипта). Шаблоны представляют собой документы в формате
    Plain XML, выгружаемые из LibreOffice.
    
    В каждом шаблоне должны присутствовать специальные слова, типа ###ДАТА###
    или ###РАБОТЫ### (полный список см. в начале каждого скрипта), которые
    скрипт заменяет на окончательные значения.
    
    **ВНИМАНИЕ:** для того, чтобы слова-шаблоны успешно заменились скриптом они
    должны иметь "чистый" (не разбитый на части) вид при просмотре самого XML
    формата файла. Чтобы убедиться, что слово не искажено, файл нужно
    открыть в простом текстовом редакторе и попробовать его там найти. Есть оно
    не находится - значит оно было разбито на части, и его нужно выправить:
    выбрать, очистить у него форматирование (Ctrl+M) и применить нужное
    форматирование снова разом ко всему слову (включая знаки ###).
