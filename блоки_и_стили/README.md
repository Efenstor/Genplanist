Блоки и стили
==

Набор динамических блоков и стилей (в основном выноски).

Некоторые блоки, напр. автокоординаты или 3D красные горизонтали, после изменения нуждаются в регенерации: из меню "Вид > Регенерировать всё" (советую сделать клавиатурную комбинацию под это действие, напр. F2).

Пока что блоки расположены довольно хаотично, т.к. всё создаётся и исправляется по мере надобности в процессе работы.

Откосы предназначены для использования совместно с функцией обрезки блоков (_XCLIP).

3D варианты красных горизонталей и выносок отличаются тем, что заполняются соответственно Z координате.
